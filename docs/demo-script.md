# 시연 대본 (공모전용)

CarMeter의 시연은 두 부분이다. ① 앱이 화면에 없어도 차량 기능 사용이 실시간으로 기록되는 장면, ② 합성 데이터로 채운 월간 고지서. 데모 빌드(`demo` 플레이버)로만 한다. 제출용 `prodRelease`에는 합성 데이터 생성기가 없다.

## 준비 (시연 전 5분)

```sh
./scripts/start-emulator.sh                         # 터미널 1
source scripts/env.sh                               # 터미널 2
./gradlew :app:assembleDemoDebug
adb install --user current -r app/build/outputs/apk/demo/debug/app-demo-debug.apk
adb forward tcp:8088 tcp:8088                       # Virtual Console: http://127.0.0.1:8088
```

- 처음 설치라면 앱을 열어 "동의하고 시작" → 알림 "허용".
- Virtual Console을 노트북 브라우저에 띄워 둔다. 기어는 P.
- 데이터를 비우고 시작하려면: 설정 → 모든 기록 지우기.

## 1부 · 실시간 기록 (약 2분)

| 순서 | 동작 | 보여줄 것 |
|---|---|---|
| 1 | 앱을 열어 고지서 상단 "● 백그라운드 기록 중" | 동의한 뒤에만 기록한다는 점 |
| 2 | 다른 앱(지도, 설정)을 띄워 CarMeter를 화면에서 내린다 | 알림 센터의 "차량 기능 사용을 기록하고 있어요" |
| 3 | Virtual Console: 운전석 시트 H1 → H3 → Off, A/C 켜기·끄기, 창문 열기·닫기, 방향지시등 | 앱이 안 보여도 기록이 쌓임 |
| 4 | CarMeter로 돌아온다 | "시트 열선", "에어컨" 등이 이번 달 표에 바로 반영 |
| 5 | Virtual Console: 기어 D | 고지서가 큰 숫자 3개로 바뀜(주행 중 간략 모드), 스크롤·버튼 없음 |
| 6 | 기어 P | 전체 고지서로 복귀 |

debug 빌드면 고지서 하단 "수집 확인 (debug)"에서 원시 구간·트립·기록률을 바로 보여줄 수 있다.

## 2부 · 월간 고지서 (약 3분)

| 순서 | 동작 | 보여줄 것 |
|---|---|---|
| 1 | 고지서 왼쪽 열 맨 아래 "데모: 합성 데이터 불러오기" | 두 달 전 1일부터 오늘까지를 약 1초 만에 생성(시드 고정, 계절 반영) |
| 2 | "‹"로 지난달 고지서 | 완결된 한 달을 그 전달과 비교 |
| 3 | 오른쪽 "기능별 사용" 표 | 이번 달/지난달 막대, "시트 열선 5시간 34분 · 새로 사용", "에어컨 -73%"처럼 날씨가 추워지며 바뀌는 사용 |
| 4 | 왼쪽 "안 쓴 기능" | "시트 통풍: 10월 0회"처럼 차가 지원하는데 안 쓴 기능 |
| 5 | 상단 기록률 | 앱이 꺼져 있던 주행이 섞여 있어 100%가 아님(예: 96%). 빈 구간을 추정으로 채우지 않는다 |
| 6 | 한 줄 팁 | 기록에서 나온 팁(예: 창문을 연 채 달린 시간) |
| 7 | 창을 좁게(포트레이트) | 같은 내용이 요약 카드로 |
| 8 | 설정 | 항목별 기록 끄기, 모든 기록 지우기, "기록은 이 차 안에만 저장돼요" |

## 시연 중 문제가 생기면

| 증상 | 조치 |
|---|---|
| Virtual Console이 안 열림 | 에뮬레이터를 재부팅했다면 `adb forward tcp:8088 tcp:8088`을 다시 |
| 상태가 "차량에 연결하지 못했어요" | 설정 → 백그라운드 기록 끄기·켜기, 그래도 안 되면 앱 재실행 |
| 고지서가 비어 있음 | 2부 1번(합성 데이터)부터 |
| 합성 데이터 수치가 이 문서와 다름 | 생성은 오늘 날짜 기준이라 달라질 수 있다. 같은 날 같은 시드면 같은 결과 |
